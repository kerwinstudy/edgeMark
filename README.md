# edgeMark

在 **Microsoft Edge** 里打开、编辑、浏览本机 Markdown 文件的**本地管理器**。

`start.command` 会用 `open -a "Microsoft Edge"` 启动页面；只有 Edge 不存在时才退回系统默认浏览器。

界面是**左右分栏**：

- **左：所见即所得**——用 Vditor 的 `ir`（即时渲染）模式，平时看不见 markdown 标记，
  光标落到某一行才显示该行的 `#`、`**` 等。就是 MarkText / Typora 那种直接编辑排版结果的感觉。
- **右：「源码 / AI 助手」两个页签**——源码是可编辑的原始 markdown，与左侧**双向同步**；
  或者切到 AI 助手就当前文档提问。

两侧的改动会互相同步。

## 快速开始

```bash
npm install          # 只有 markdown-it 一个依赖
npm start            # 然后手动打开 http://localhost:5178
```

或者直接**双击 `start.command`**：它会自动装依赖、启动服务，并用 Edge 打开页面。
终端窗口保持打开表示服务在运行；关掉终端或按 `Ctrl+C` 即停止。

首次打开会让你选一个**根目录**，之后所有浏览和编辑都被限制在这个目录内。

## 快捷键

左侧（所见即所得）沿用 Vditor 自带的一套，另外补了 MarkText 的标题快捷键：

| 操作 | 快捷键 |
| --- | --- |
| 标题 1~6 | `Cmd+1` ~ `Cmd+6` |
| 代码块 | `Cmd+Shift+K` |
| 加粗 / 斜体 | `Cmd+B` / `Cmd+I` |
| 链接 | `Cmd+K` |
| 撤销 / 重做 | `Cmd+Z` / `Cmd+Y` |
| 保存当前标签 | `Cmd+S`（全局，焦点在哪都生效） |
| 列表自动续行 | `Enter` |

**关于 MarkText 的快捷键。** MarkText 里 `⌥⌘C` 是代码块、`⌥⌘U` 是无序列表、`⌥⌘Q` 是引用——
这些在 Electron 里是自由键，**但在浏览器里已经被占用了**：`⌥⌘C` 是 Edge 的「检查元素」，
`⌥⌘U` 是「查看源代码」，都属于浏览器级快捷键，页面 `preventDefault()` 拦不住。
所以代码块改用 Typora 的 `Cmd+Shift+K`。其余 `⌥⌘` 前缀的快捷键同理，需要换键才能用。

`Cmd+1`~`Cmd+6` 的实现见下面「实现说明」。

## 实现说明

**左侧为什么选 Vditor。** MarkText 的编辑器内核 Muya 就在本机 MarkText 的 `app.asar` 里，
它才是「MarkText 本体」。但 Muya 的源码是为 Vite 写的（含 `katex/dist/katex.css?inline`
这类 `?inline` 导入），要跑起来必须先引入 esbuild 打包并写插件处理，还要拉进 mermaid / katex /
vega / flowchart 等 22 个重依赖。Vditor 的 `dist/index.min.js` 是自包含 UMD，一个 `script`
标签即可，`ir` 模式的行为与 Typora 一致，所以选了它。

**完全离线。** Vditor 默认从 unpkg 拉 Lute 引擎、图标、highlight.js、KaTeX、以及
mermaid / plantuml / echarts 等图表渲染库。这里把 `cdn` 指向 `/vendor/vditor`，
并按它的目录约定把资源**全部**拷到本地（约 22MB）。

> 注意：这些图表库是**按需加载**的——文档里出现 ```` ```plantuml ```` 之类的代码块时，
> Vditor 才会去取对应脚本。而它的加载器是 `<script>` + `onerror → reject`，且调用处没有
> `.catch()`，所以**少任何一个文件都会变成一条未处理的 Promise 拒绝**（页面上会显示红条）。
> 早期版本我裁掉了这些库，就踩了这个坑，现已全部补齐。

**内容真源只有一个。** 每个标签持有一个 `CodeMirror.Doc`（右侧源码面板），它是该文件内容的
唯一真源，Vditor 只是它的一个视图。这样保存时直接取 doc 即可，不用纠结两边谁新。

**双向同步与死循环防护。** 两侧任一变化都推给另一侧，用 `state.syncing` 标志阻断回环。

**大文件性能（重要）。** 三个措施，缺一不可：

1. **源码面板不设 `viewportMargin: Infinity`。** 设了会让 CodeMirror 把整个文档渲染成 DOM
   而不是只渲染可视区域，大文件下直接卡死。这是最容易踩的坑。
2. **Vditor → 源码用最小差异替换，不用 `setValue`。** 全量 `setValue` 会重建整个文档的 DOM，
   每敲一个字都卡。改成算出公共前后缀、只 `replaceRange` 变化的那一段：
   500KB 文档下单次按键约 1.3ms，实际只替换 1 个字符。
3. **超大文件关闭所见即所得渲染。** Vditor 没有虚拟滚动，是整篇文档一次性建成 DOM；
   CodeMirror 有视口渲染，大文件反而没问题。所以超过 `WYSIWYG_MAX_CHARS`（当前 300000 字符）
   就退回「只用源码面板编辑」，左侧显示提示。阈值在 `public/app.js` 里可调。

源码 → Vditor 的方向防抖 600ms（每次都要让 Vditor 重新解析并重建 DOM，代价高）；
切换标签时会清掉排队的同步，避免落到错误的标签上。

**`Cmd+1`~`Cmd+6` 怎么接的。** Vditor 把等价的标题功能硬编码在 `⌥⌘1`~`⌥⌘6` 上，内部走
`It(vditor, "## ")`，和工具栏的标题按钮同一条路径。与其去调它的内部函数（不是公开 API），
不如拦下 `Cmd+N` 再派发一个 `altKey=true` 的同键事件，让它自己的成熟逻辑处理。
派发出去的事件带 `altKey`，不会再命中这个分支，不会递归。

**已知取舍。** 左侧（Vditor）的撤销历史不跨标签保留——切换标签时用的是
`setValue(md, true)`，会清空撤销栈。右侧源码面板的撤销历史是按标签各自的 Doc 保留的。
另外左侧打字时右侧会重设内容，所以右侧的光标位置不保留（滚动位置会保留）。

## 接口

所有路径参数都是**相对根目录**的路径，服务端会拒绝任何越出根目录的请求。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/config` | 当前根目录、最近使用、常用目录 |
| POST | `/api/config/root` | 切换根目录，`{ root: "/abs/path" }` |
| GET | `/api/tree?dir=<rel>` | 列出某目录的直接子项（目录 + 可编辑文本文件） |
| GET | `/api/file?path=<rel>` | 读取文件内容 |
| PUT | `/api/file` | 保存，`{ path, content }` |
| POST | `/api/file` | 新建文件，`{ path, content? }` |
| POST | `/api/dir` | 新建文件夹，`{ path }` |
| POST | `/api/rename` | 重命名 / 移动，`{ path, to }` |
| DELETE | `/api/entry` | 删除，`{ path }` —— **移入废纸篓，不做永久删除** |
| GET | `/api/ai/config` | AI 配置。**只回 `hasApiKey` 布尔值，不回密钥本身** |
| POST | `/api/ai/config` | 写 AI 配置，`{ baseUrl, model, apiKey? }`。`apiKey` 省略=不改，`""`=清除 |
| POST | `/api/ai/chat` | 转发一次对话，SSE 流式返回。`{ messages }` |

### 文件管理

目录树支持新建文件 / 新建文件夹 / 重命名 / 删除。新建的位置跟随**最后点选的目录**
（或最后打开文件所在的目录），对话框里会写明具体位置。

**删除一律移入 macOS 废纸篓，绝不永久删除。** 只做同卷 `rename`；如果根目录在外接硬盘等
其他卷上会失败，这时**明确报错而不是退化成硬删**。废纸篓里已有同名文件时会加时间戳后缀，
不覆盖。

不允许创建以 `.` 开头的名称 —— 目录树本来就不显示隐藏文件，建了会「消失」，所以直接拒绝。

### 配置存在哪里

根目录、最近使用记录、AI 配置（含 API Key）都存在**用户目录**，不在项目目录里：

```
~/.edgemark/config.json     目录 0700、文件 0600（仅本人可读写）
```

放在项目目录外，是为了复制 / 分享 / 打包项目时不会把 API Key 一起带走。

- **明文存储，未加密。** 和 `~/.aws/credentials`、`~/.npmrc` 同一级别。
- **密钥不回传浏览器。** `GET /api/ai/config` 只回 `hasApiKey` 布尔值，页面里、浏览器存储里、
  网络请求里都没有它。
- **每次写入都会强制 `0600`**，即使权限被改松也会拧回来。
- 服务只监听 `127.0.0.1`。
- 旧版本把配置放在项目的 `.edgemark-config.json`，**首次启动会自动迁移**（校验写回内容一致后才
  删除旧文件）。`.gitignore` 里仍保留该条目作为兜底。

**用 `EDGEMARK_CONFIG` 指定别的配置文件**（跑自动化测试时务必用，否则会写到真实配置上、
把里面的 API Key 覆盖掉）：

```bash
EDGEMARK_CONFIG=/tmp/test-config.json npm start
```

设了它之后不会做旧配置迁移。

## AI 助手

右侧面板顶部有「源码 / AI 助手」两个页签。点「设置」填三项：

- **Base URL** —— 填 API 根地址（如 `https://api.openai.com/v1`），服务端会自动补 `/chat/completions`；
  直接把完整端点粘进来也认。任何兼容 OpenAI 接口格式的服务都可以（OpenAI、DeepSeek、Moonshot、
  本地 Ollama / vLLM / LM Studio 等）。
- **Model** —— 模型名，如 `gpt-4o-mini`。
- **API Key** —— 留空表示不修改已保存的密钥。

对话时**每次发送都会重新读取当前标签页的完整内容**，所以边改边问也能反映最新版本。
文档超过 60000 字符会截断并在提示里注明。

### 让 AI 直接改文件

直接在对话里说「把第二节标题改成…」「删掉最后一段」即可。**AI 不会偷偷改文件** ——
它会输出结构化的修改块，由前端解析成 diff 预览，**你点「应用到当前文件」才生效**。

协议（写进系统提示词，见 `public/app.js` 的 `AI_SYSTEM_PROMPT`）：

```
<<<<<<< SEARCH
（要被替换的原文，必须与文档逐字符一致）
=======
（替换后的内容，留空表示删除）
>>>>>>> REPLACE
```

一个块只改一处，可以连续多个；只输出改动片段，不输出整个文件；不需要改动时不输出任何块。

**为什么不用 function calling**：各家「兼容 OpenAI」的端点对工具调用的支持参差不齐，
用结构化文本块对任何模型都通用，而且天然可以在界面上做人工确认。

**应用时的几条安全约束**：

- **精确匹配 + 必须唯一。** 找不到、或出现多次，都拒绝应用并说明原因 —— 不做模糊猜测，
  避免改错地方。
- **唯一的容错是行尾空白。** 模型最常见的偏差是行尾多/少空格，这时退化成「逐行忽略行尾空白」
  匹配，并在结果里标明不是精确匹配。
- **逐处独立。** 某处失败不影响其他处，会列出哪些跳过、哪些应用。
- **只改内存，不落盘。** 应用后只是标记为「未保存」，仍由你按 `⌘S` 决定。
- 应用前会**基于当前文档内容重新校验**一遍，所以 AI 回复之后你又手动改过文件也没关系。

## AI 助手（实现选择）

- **请求必须经本地服务转发**，浏览器不直连上游。原因是绝大多数 LLM API 不允许跨域，
  而且密钥不该出现在页面里。上游返回的 SSE 会在服务端被收敛成
  `{"delta":"..."}` / `{"error":"..."}` / `[DONE]` 三种事件，前端不用关心各家格式差异。
- **密钥不回传浏览器。** `GET /api/ai/config` 只回 `hasApiKey`；设置界面里密钥框永远是空的，
  留空即不修改。
- **文档用 `===== 文件内容开始 =====` 这种显式分隔符包裹，而不是代码围栏**——
  文档里本来就可能含 ` ``` `，用围栏会被提前截断。
- 服务只监听 `127.0.0.1`，不对外暴露。

## 当前范围

已经做到：

- 选择根目录，懒加载目录树（目录可展开，只列出可编辑的文本文件）
- **文件管理**：新建文件 / 新建文件夹 / 重命名 / 删除（进废纸篓），树节点悬停出现操作按钮
- **左侧所见即所得编辑**（Vditor `ir` 模式）：看不见 markdown 标记，光标所在行才显示；
  工具栏 + `Cmd+1~6` 等快捷键
- **右侧「源码 / AI 助手」页签**：源码可编辑，与左侧双向同步
- **多标签页**：可同时打开多个文件来回切换，标签上有未保存小圆点，`×` 或鼠标中键关闭
- **AI 文档助手**：自动带上当前文件全文，流式输出，可随时停止
- **AI 直接改文件**：输出结构化修改块 → 界面显示 diff → 你确认后才应用（不自动落盘）
- `Cmd+S` 保存当前标签，关闭未保存的标签前确认，页面关闭前也会拦一次
- 拖拽调整目录树 / 所见即所得区 / 源码区宽度
